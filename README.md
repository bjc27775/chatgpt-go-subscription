## 充值 Go 之前，把广告这件事看清楚

这是现在买 Go 和早几个月买最大的区别：Go 是付费档，但**不保证无广告**。

OpenAI 在宣布 Go 全球上线的同时，就提到会在美国测试免费档和 Go 的广告。实际推进比公告更快：2 月 9 日美国开始对部分登录的成年用户测试；4 月中旬铺到澳大利亚、新西兰和加拿大；之后扩展到英国；8 月又宣布将进入墨西哥、巴西、日本和韩国。Plus、Pro、Business、Enterprise（以及 Education）保持无广告。

呈现形式上，广告出现在回答结束后的下方，带赞助标识，和正文视觉上分开，官方表示广告主不能改动 ChatGPT 的回答。但另一件事要分清——广告的筛选可能参考当前对话内容；如果你开启了个性化广告，过去的对话和记忆也会参与进来。

想控制这些，进 Settings → Ads controls：可以关闭个性化广告、查看某条广告为什么展示、清除用于广告的数据（清除最长需要 30 天完成）。广告主拿不到你的聊天记录、记忆、姓名、邮箱或精确位置，只能拿到汇总的展示和点击数据。

所以对广告的态度可以很简单：能接受「便宜但可能有广告」，Go 的性价比就成立；要确定性，加钱上 Plus。
